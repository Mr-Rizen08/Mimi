# Mimi
Вы же помните Скрепыша ? Так вот - это более умная и милая версия, ввиде питомцев с функциями локального ии


![Мими идёт](mini/tests/walk.gif)

Данный код тестировался на линуксе с Wayland, но из-за не которых проблем , я советую установить библиотеку для x11

__Debian__
```

sudo apt install libxcb-cursor0
```

__Arch__
```
sudo pacman -s xcb-unit-cursor
```
__Fedora__
```
sudo dnf install xcb-unit-cursor
```
